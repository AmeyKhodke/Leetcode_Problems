## How Solutions Are Added

1.  Solve a problem on [LeetCode](https://leetcode.com/).
2.  Submit the solution and confirm that the result is **Accepted**.
3.  LeetHub detects the accepted submission and uploads the solution to
    this repository.
4.  Review the new files and commit history on GitHub.

If automatic syncing does not work, I can use LeetHub's **Sync an
accepted submission** option with the submission URL.
